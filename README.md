# 🏦 KRUSTY KRAB TRADING BOT

Bot Telegram untuk sinyal trading XAU/USD, BTC/USD, ETH/USD, dan 6 pasangan Forex.

## 🚀 Fitur
- 12+ Indikator Teknikal
- AI-Powered Scoring
- 3 Level Take Profit
- Database History
- Performance Tracker

## 📊 Aset yang Didukung
- 🥇 XAU/USD (Emas)
- 🪙 BTC/USD (Bitcoin)
- ⚡ ETH/USD (Ethereum)
- 💶 EUR/USD, 💷 GBP/USD, 💴 USD/JPY
- 🇦🇺 AUD/USD, 🇳🇿 NZD/USD, 🇨🇦 USD/CAD

## 🔧 Cara Deploy ke Railway
1. Fork repository ini
2. Buat akun Railway
3. Deploy dari GitHub
4. Set Environment Variables:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
